1P01 工作流模型与文件处理指令

发表于2026-09-10|更新于2026-09-10
|浏览量:

源文件的概念

打开编译器呈现源代码的文件

对于c++来说就是后缀名为.cpp的文件

编译阶段与运行阶段

编译过程就是编译器翻译源代码的过程

运行阶段就是编译完成后机器开始根据翻译后的源代码执行命令的阶段

编译 = 将源代码（人类可读的文本）翻译成机器码（计算机可执行的指令）的过程。 编译器就是起到翻译的作用 把你的源代码翻译给机器看 为后续的机器运行阶段做准备

编译阶段分为预处理(纯文本处理)和正式编译阶段

写源文件→ 预处理→ 正式编译→ 链接阶段 →诵薪锥�

该流程称为工作流模型，表示代码从编写到运行的基本过程。

其中，链接阶段仅在多文件程序中涉及，此处仅作概念性了解，不作详细展开。

预处理指令

以 # 开头的指令称为预处理指令（或源文件文本处理指令）。

#include 的作用

#include  或 #include “text” 的作用是： 将指定文件（text）的内容复制到当前文件中，并替换掉该 #include 指令本身，从而实现外部文件的插入。

#include <> 与 #include “” 的区别

此外，#include “” 也可以通过编译器设置添加额外的搜索路径。

什么是头文件/预处理文件?

以#include<>指令给源文件在预处理阶段做补充的文件叫做头文件

在处于预处理阶段时 #include<头文件>这个文本处理指令就是为了把头文件复制粘贴过来

比如#include<stdio.h>这个形式 就是把stdio.h这个头文件调用过来

在C++中通常用替代以符合命名空间规范

#include<windows.h>

long long a=GetTickCount(); //get 获取tick 音译滴答的时钟声count 计数

功能是是获取一个毫秒级当前时间 只能用long long长度储存

可以写一个代码运行时常计时器

常用万能头

万能头文件就是包含很多#include<头文件>的头文件

我们来推演一下 万能头文件a.h写了#include<b.h> #include<c.h> #include<d.h>

那么源文件中执行#include<a.h> 就是把#include<b.h> #include<c.h> #include<d.h>

插入到这个位置 然后再处理三个#include指令 那么就把b.h c.h d.h的内容都给给插入进来了

#include <bits/stdc++.h> //C和C++的万能头

#include‌<stdio.h>‌ //C的万能头

在不做大型项目时 我们一般直接调用万能头(包含对应的很多头文件 相当于整合工具箱的工具箱) 来避免用到的头都include一遍 来节省时间

但是大型项目尽可能用啥include啥不要乱用万能头 不然你会发现声明一个变量y3 结果会报错 因为y1 y2 y3 是保留标识符 他们是一个功能函数的名字

#if // 如果条件为真

#else // 否则

#elif // 否则如果

#include // 包含文件

#pragma // 编译器指令

#error // 产生错误信息
