源文件的概念

源文件是编译器能够直接打开并读取的、包含源代码的文件。在 C++ 中，源文件就是后缀名为 .cpp 的文件。

编译阶段与运行阶段

编译是把源代码（人类可读的文本）翻译成机器码（计算机可执行的指令）的过程；编译器就是起到「翻译」作用的工具，它把源代码翻译给机器看，为后续的运行阶段做准备。

运行阶段是编译完成后，机器开始根据翻译得到的指令执行命令的阶段。

编译阶段又分为预处理（纯文本处理）和正式编译两个阶段。

代码从编写到运行的基本流程称为工作流模型：

写源文件 → 预处理 → 正式编译 → 链接 → 运行

其中链接阶段只在多文件程序中才会涉及，这里仅作概念性了解，不作展开。

预处理指令

以 # 开头的指令称为预处理指令（也叫源文件文本处理指令）。

#include 的作用

#include <text> 或 #include "text" 的作用是：把指定文件（text）的内容复制到当前文件中，替换掉这条 #include 指令本身，从而实现外部文件的插入。

什么是头文件（预处理文件）

在预处理阶段，通过 #include 指令给源文件做「补充」的文件，就叫做头文件。

预处理阶段执行 #include <头文件> 这条文本处理指令时，就是把这个头文件的内容复制粘贴到当前源文件里。例如 #include <stdio.h> 就是把 stdio.h 这个头文件的内容调用进来。

常见的头文件及功能

提供输入输出流功能，包含核心对象：

  • cin：标准输入流（键盘输入）
  • cout：标准输出流（控制台输出）
  • cerr / clog：错误流和日志流
  • 支持运算符 << 和 >> 进行格式化 I/O 操作

提供数学函数库，包含：

  • 基本运算：sqrt()、pow()、abs()
  • 三角函数：sin()、cos()、tan()
  • 对数 / 指数：log()、exp()
  • 所有函数均支持浮点数运算

包含常用算法操作：

  • 排序：sort()、stable_sort()
  • 查找：find()、binary_search()
  • 数值处理：max()、min()、accumulate()
  • 适用于容器（如数组、vector）的泛型算法

<stdio.h>

C 语言标准 I/O 库，提供：

  • printf() / scanf()：格式化输入输出
  • 文件操作：fopen()、fread()
  • 在 C++ 中通常用 <cstdio> 替代，以符合命名空间规范

常用万能头

万能头文件就是包含很多 #include <头文件> 的头文件。

推演一下：假设万能头 a.h 里写了 #include <b.h>、#include <c.h>、#include <d.h>，那么源文件里执行 #include <a.h>，就是把这三条 #include 指令插入到当前位置，然后再依次处理它们，于是 b.h、c.h、d.h 的内容就都被插入进来了。

在做小型项目时，一般直接调用万能头（它包含了对应的很多头文件，相当于「整合了工具箱的工具箱」），避免用到一个头就 include 一次，从而节省时间。

但在大型项目中，尽量「用什么 include 什么」，不要乱用万能头。否则可能会发现：声明一个叫 y3 的变量会报错——因为 y1、y2、y3 是保留标识符，它们是某个功能函数的名字。
