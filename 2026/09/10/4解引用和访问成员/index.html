1P04 解引用和访问成员

发表于2026-09-10|更新于2026-09-10
|浏览量:

需要解引用的情况

STL库有关容器的算法返回值可能返回迭代器

例如max_element()

这时候最大值max_it是被包装的 我们需要解引用(*max_it)来打开包装从而得到具体的值

解引用并访问其成员

biao.begin()是一个叫biao容器通过算法返回的迭代器

那么解引用这个迭代器(*biao.begin()) 得到的这个元素

可以是int值 也可以是结构体 也可以是一个数组

如果 需要解引用的对象是结构体

那么可以对解出来的迭代器值(*biao.begin()) 继续访问子对象 (biao.begin()).first 如果用->的组合代替(). 的形式就成了 biao.begin()->first

当然结构体未被封存在迭代器里 那么直接 jiegouti.first 就能得到成员值

访问成员再解引用

*a.指针成员 这个顺序是先访问a的指针成员再解引用 得到成员指针的值

a在这里一般是类 请到 5类与实例 再去详细了解

访问成员函数

很多容器带有成员函数

string类型容器里封存了很多子函数 比如说对于一个叫str的string类型变量

string str,s;

str.erase(1, 1);//代表把str从序列1向后删一个元素

str.find(s); // str里找s 并返回s第一个字符在str里的索引

结构体自创的成员函数

using namespace std;

#include<bits/stdc++.h>

struct xiaomao {

int id;

string name;

void haha(int awa) {

cout << id+awa << name << “!\n”;

}

};

int main() {

xiaomao object;//bbejct 成为了xiaomao类型的变量

object.id = 123;

object.name = “我是小猫”;

object.haha(123);//调用object的成员函数haha()

}

【输出结果】246我是小猫
