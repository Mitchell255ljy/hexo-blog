作用域空间

作用域空间：不需要 if/else 也能存在

很多人以为 { } 必须跟 if、while、函数之类的关键字，其实不是。

{ }** 可以独立存在**，它就是一块“作用域空间”。

作用域空间利用“退出即销毁”的特性，用来限制变量的生命周期，避免资源占用和命名冲突

命名空间和namespace关键字

命名空间的内容永久存在、跨文件可见、需要用前缀访问

std 是 C++ 标准库中的命名空间，封装了大部分的标准库实现

C++ 标准库中的大多数名称（如 cout、vector、sort）定义在 std 命名空间中。 在默认情况下，使用它们时需要加上 std:: 前缀

更换命名空间调用前缀

namespace fs=std::filesystem

原本需要用std::filesystem::调用的简化成成了 fs::调用

#include //这个库的所有内容都是标准库下的 并且自身也有一套命名空间 所以你想要调内部的功能需要 std::filesystem::这样调用

namespace fs = std::filesystem;//把std::filesystem::调用 简化成fs::调用

using

给类型起别名

有很大的局限性 就只能对类型进行操作(不能using a=2这样定义值)

using ll=long long //using作用给东西起别名

命名空间操作

using namespace std;//导入整个std命名空间

以后的cout cin max()就去除了前面的命名空间std::前缀

单个的命名空间引用

#include<bits/stdc++.h>

using std::cout;//以后的cout不用写std::前缀了

关于using namespace std;作用

C++标准库的所有内容（如cout、string等）被封装在std命名空间中，若不使用该指令，需通过std::cout等形式调用。

通过using namespace std; 可简化代码，减少重复输入std::的冗余

C++标准库 里包含的(包含max()等) (里面是我们常用的vector容器） （包含cout cin 基本输出方式) 等头文件 都是我们C++常用到的 要是不用using namespace std; 那么每个头文件里面包含的 函数 容器 都要前接std::再使用

例如

#include

using namespace std; // 引入std命名空间(using是使用的意思,space是空间的意思)

int main() {

cout << “Hello”; // 直接使用cout而非std::cout

return 0

}

可使用using std::cout; 等语句单独引入特定名称，后续无需再加前缀

#include

using std::cout;

using std::endl;

int main() {

cout << “Hello” << endl; // cout合法

}

宏命令#define

宏命令就是预处理指令的一种

define 的英语词义就是 “ㄒ�”

最简单的应用就是#define 变量a 空

实现空定义变量a

给类型进行文本替换

#define int long long //#dfine 给文字进行替换 这个using就无法做到 固有字int 的替换 using int=long long 会直接报错

//对了 int main() { 用了define之后也会报错 因为main()函数仅支持int型 不支持long long 这时候我们用int 的等价形式signed

即为 signed main()

定义变量和值

#define PI 3.14159 //把PI这个替换为3.14159

上至类型替换 下到变量替换 都能实现 体现了文本替换的特性

这就是using 实现不了的 using仅能操作类型 而#define 就是简单暴力的文本替换 可以实现把PI修改为3.13159 实现值的定义

宏函数实现

#include <stdio.h>

#define LOOP_WITH_LOG_FOR(count, action) \

for(int __done = 0; __done < 1; __done++) \

action; \

}

int main() {

int sum = 0;

LOOP_WITH_LOG_FOR(3, sum += __i;

printf(“累加: %d, 总和: %d\n”, __i, sum);

);

return 0;

}

常见的头文件里写重复调用宏

#pragma once

原理为

#ifndef MYJIAOHU_H // MYJIAOHU_H 有没有定义？没有！#if no define =#ifndef

#define MYJIAOHU_H // ✅ 那就定义它

class myjiaohu {} // ✅ 包含头文件内容
