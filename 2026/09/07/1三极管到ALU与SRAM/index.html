三级管的结构

在标准电路图绘制规范中，三极管的集电极（C）位于基极（B）左侧，发射极（E）位于右侧。

三极管分为NPN和PNP两种类型，二者的本质区别在于电流流向和电压极性完全相反：NPN型电流从集电极（C）流向发射极（E），因此其集电极（C）接高电压，发射极（E）接低电压；而PNP型电流从发射极（E）流向集电极（C），因此其发射极（E）接高电压，集电极（C）接低电压。本课程默认只讨论NPN型，即集电极（C）接高电压的情况。

NPN型三极管的三个电极各司其职：

发射极（E）：作为载流子（电子）的发射源，电子由此极注入基区。物理层面实际迁移的粒子为电子，其运动方向与常规电流方向相反。

集电极（C）：作为载流子的终点，由发射极注入的大部分电子最终被集电极所收集，故得名”集电极”。

基极（B）：作为控制电极。当B-E间施加的正向电压达到或超过发射结导通阈值（硅管约0.6V~0.7V）时，发射结正偏，产生基极电流（注意：基极需要在施加电压后产生一个持续的基极电流才能维持E-C间的导通，这意味着基极存在固有的电流消耗。这一特性正是三极管与后文将要介绍的MOS管相比的显著劣势，也是阻碍三极管实现大规模集成化应用的根本原因），E-C间形成电子通道，三极管导通；当B极电压低于阈值或为低电平时，发射结截止，E-C通道关断。基极不承担主电流的传输，其功能仅为控制主通道的通断。

本图采用NPN三极管驱动LED电路，严格遵循NPN型三极管的标准原理图画法：集电极（C）位于基极（B）左侧，且集电极（C）接高电压（VCC），发射极（E）接低电压（GND）。 LED串联于集电极回路中，通过基极信号控制三极管的导通与关断，从而实现对LED的开关控制。

逻辑门

当两个NPN三极管串联连接时，其导通/截止状态共同决定串联通路的总通断。将两个基极的加电情况分别定义为命题变元 A 和 B（高电平为“1”，低电平为“0”）：

仅当 A = 1 且 B = 1（两个基极同时为高电平，两个三极管同时导通）时，串联通路才完全导通，输出为“1”。

其余三种情况（A=0,B=0；A=0,B=1；A=1,B=0）中，至少有一个三极管截止，通路关断，输出为“0”。

该逻辑关系等价于与门（AND）。

或门（OR gate）的等效实现

若将两个NPN三极管改为并联连接，则构成或门逻辑。此时，两个基极信号仍为命题变元 A 和 B，集电极与发射极分别并接在一起作为输出端：

只要 A = 1 或 B = 1（至少一个基极为高电平，对应三极管导通），并联通路中便存在一条闭合支路，总输出为“1”。

仅当 A = 0 且 B = 0（两个基极均为低电平，两个三极管均截止）时，两条支路全部断开，输出为“0”。

该逻辑关系等价于或门（OR）。

非门（NOT gate）的等效实现

若将单个NPN三极管接成共发射极电路，发射极直接接地，集电极经负载电阻接电源正极，同时从集电极引出输出端F，则构成非门逻辑。此时，基极信号为命题变元A，集电极输出为F（高电平为“1”，低电平为“0”）：

当 A = 0（基极为低电平，三极管截止）时，集电极与发射极之间近似开路，集电极无到地的导通回路，输出端F通过负载电阻被上拉至电源正极，输出 F = 1（高电平）。

当 A = 1（基极为高电平，三极管饱和导通）时，集电极与发射极之间近似短路，由电源正极经负载电阻流入集电极的电流，经三极管导通通道流向发射极并到达地，此时输出端F被下拉至接近地电平，输出 F = 0（低电平）。

该逻辑关系等价于非门（NOT）

现在，我们已经认识了三种最基本的逻辑门。

在此基础上，我们引入一种新的、也极为重要的逻辑门——异或门（XOR gate）。它的逻辑功能可以这样描述：设有两个命题变元 A 和 B 作为输入，当且仅当 A 和 B 中恰好只有一个为 1（即 A=1、B=0，或 A=0、B=1）时，输出为 1；而当两个输入全为 0 或全为 1时，输出均为 0。换句话说，异或门判断的是“两个输入是否不同”——不同则输出 1，相同则输出 0。

异或门虽然功能独特，但它并非全新的基础元件，完全可以用我们已经掌握的与门、或门和非门组合构造出来。

二进制全加器

现在我们已经了解了逻辑门是什么，接下来我们拿它们来构建点更有意思的东西：二进制加法器。

我们先从最简单的情况入手——一位二进制加法。假设有两个一位二进制数 A 和 B 分别作为两个输入（每位只能是 0 或 1），我们要计算 A + B 的结果。这个结果可能是一位（如 0+0=0，0+1=1，1+0=1），也可能是两位（如 1+1=10，即结果为 0，同时向高位产生一个进位 1）。因此，一位加法不仅产生一个“和”输出，还可能产生一个“进位”输出。

这种只考虑两个输入、不考虑来自低位的进位的加法电路，称为半加器（Half Adder）。

但实际的多位二进制加法中，低位运算产生的进位需要参与到高位的运算中。也就是说，对于除了最低位以外的每一位，我们实际上有三个输入：本位的两个加数 Aᵢ 和 Bᵢ，以及来自低位的进位 Cᵢ₋₁；同时产生两个输出：本位的和 Sᵢ 和向高位的进位 Cᵢ。

这种能够同时处理两个加数和低位进位三者相加的电路，称为全加器（Full Adder）。

将多个全加器逐位级联——低位产生的进位送往高位的进位输入端——就可以构成多位二进制加法器，从而实现任意位宽的二进制的加法运算。

以三位二进制数 101 与 111 的加法运算为例，其对应的多位二进制加法器电路，由三个全加器首尾串联构成。

图中从左至右依次排列的三个全加器，分别对应二进制加法中的高位至低位的每一位运算

依此类推，若要计算两个八位二进制数之和，则需要八个全加器逐位串联——每一位对应一个全加器，低位进位依次向高位传递，从而完成整个八位加法运算。

我们将上述由八个全加器串联而成的结构称为八位加法器（8-bit Adder）。它可以被整体封装为一个独立的模块，将内部复杂的级联电路隐藏于其中，仅对外暴露两个八位数据输入端（A₇A₀ 和 B₇B₀）、一个八位和输出端（S₇~S₀）以及一个溢出端（Carry Out / Overflow）。这个溢出端实际上就是最高位（最左侧）全加器的进位输出端，它直接引出作为整个加法器的溢出标志，用于指示运算结果是否超出了八位二进制数的表示范围。

二进制译码器

在掌握了八位加法器的构建之后，我们自然可以依此类推，构造出八位减法器（Subtractor）、八位增量器（Incrementer）和八位减量器（Decrementer）——它们分别对应着二进制运算中的加、减、加一、减一四种基本算术操作。

现在，我们考虑一个更高层次的需求：算术逻辑单元（Arithmetic Logic Unit，简称 ALU）。它应当接收两个八位二进制数作为输入，同时接收一个用于选择运算类型的控制信号，最终通过一根八位输出线给出该运算的结果。为了实现这样一个功能模块，我们面临两个核心问题：

  1. 输入端连接问题：两个八位输入数如何同时接入上述四种不同的算术运算器（加法器、减法器、增量器、减量器）？增量器和减量器只有一个数据输入端，那么另一个输入端应当如何处理（例如固定接何值）？但更深层的问题是：控制信号本身只是一个二进制编码，它如何“告诉”各运算器应该执行哪种运算？——换言之，选择信号需要以某种方式作用于这些运算器上，使得被选中的运算器能够“激活”并输出有效结果，而其他运算器要么不工作、要么其输出被忽略。

  2. 输出端汇总问题：四个运算器各自独立产生一个八位结果，但我们只有一根八位输出线，如何根据选择信号从四个可能的运算结果中选中唯一一个，将其传递到最终的输出端？

从接线层面来看，无论是将两个八位输入数同时接入四个运算器（输入端问题），还是将四个运算器的输出汇总到一根输出线上（输出端问题），其物理连线本身并不复杂——只需将对应的数据线并行连接即可。

真正的难点在于如何设计选择运算类型的控制信号，以及该信号如何准确地“指挥”这些接线完成对应的功能。

为了解决这一难题，我们引入二进制译码器（Binary Decoder）。译码器能够将输入的一位二进制编码，转换为对应输出线上的有效信号（即从多根输出线中仅使能一根），从而实现对不同运算器的选通控制。

在该电路中，汇编指令 00010001 的第3、4位被提取出来作为操作码，用以指示本次执行哪种运算。该两位控制信号先送入二进制译码器，译码器将其解码为四条选通线中唯一的激活信号（高电平有效）。与此同时，两个八位输入数被并行地送到全部四种运算器的输入端，各运算器同时工作并各自产生一个八位结果。在输出侧，每个运算器的输出都接有一个八位与门，而译码器输出的四根选通线分别控制这四个与门的开启与关闭——只有被激活的那一路与门允许数据通过，其余三路均被强制输出为零。最终，输出线上得到的便是所选运算的对应结果。

二进制译码器的设计原理

译码器的核心思想可以概括为：用 n 根输入线，控制 2ⁿ 根输出线中唯一一根的选通。具体来说，如果我们需要选通的总路数在 5 到 8 之间，那么只需用三位二进制数即可完成对所有线路的编号。例如，我们可以将八条待选线路依次编号为 000 号、001 号、010 号、011 号、100 号、101 号、110 号、111 号——每个编号对应一个三位二进制码。

相应地，译码器的输入端也设计为三个，每一位对应二进制编码中的一位（高位到低位）。通过向这三个输入端分别施加高电平（1）或低电平（0），即可输入一个三位二进制数，译码器内部电路将其解码，并在对应的输出线上产生有效信号（高电平），其余七条输出线则保持低电平。这样一来，仅用三根输入线，就能从八根输出线中精确选中唯一一路，从而实现“多选一”的控制功能。

两个八位数据输入端：接收两个参与运算的八位二进制数（对于增量器和减量器这类单操作数运算，第二个输入端的值不影响运算结果，可视为无关项）；

八位运算结果输出端：输出本次运算的八位结果；

附加信息输出端：如溢出标志（Carry Out / Overflow）等额外状态信息。

内存

整理后的完整版本：

上图所示结构称为锁存器（Latch），它是一种由逻辑门构成的存储单元，具备记忆一位二进制数据的功能。其基本工作过程如下：

首先，将 Reset 端保持为低电平（0），确保初始状态下没有 Set 信号被记录。此时，与门只有一个输入端为高电平（来自或门的反馈），另一个输入端为低电平（Reset=0），因此与门不导通，右端输出为 0。

当 Set 端输入高电平（1）时，或门被导通，其输出变为高电平并送入与门的一个输入端。此时与门的两个输入端均为高电平，与门导通，输出端变为 1。同时，由于输出端通过回路反馈至或门的另一个输入端，即使 Set 端随后恢复为低电平，或门仍能保持导通状态——这意味着电路“记忆”了它曾经被置位（Set）过。

当需要清除该记忆时，只需将 Reset 端置为高电平（1）。此时与门的一个输入端被拉低，与门变为不导通，输出端恢复为 0。即便存在反馈回路，该操作也能成功删除已存储的状态。

由此可见，该锁存器的两个输入端功能明确：Set 端用于“写入/记忆”，Reset 端用于“清空/擦除”。

现在来看一个特殊情况：如果 Set 和 Reset 同时置为 1，就相当于要求电路“写入”和“清除”同时进行。这在逻辑上本身就说不通，既没有实际意义，也暴露出一个设计隐患。

在上图所示的这种锁存器中，Reset 为 1 时输出被强制置 0，结果倒是确定的，看起来没什么歧义。但问题在于——锁存器的具体实现方式并不唯一。有些设计中 Set 端拥有更高优先级，此时 Set 和 Reset 同时为 1 的结果就会变成 1。换句话说，同一个输入组合，换了一个锁存器可能得到完全不同的输出。这种“因型号而异”的行为，显然是我们在逻辑设计中所不希望看到的。

为了解决这个问题，避免 Set 和 Reset 同时为 1 带来的不确定性，我们引入门控机制，构成门控锁存器（Gated Latch）。它将原先的 Set 和 Reset 两个端口合并为数据输入（Data） 和写入使能（Write Enable）。数据端决定要写入的值（0 或 1），而使能端充当“写入开关”——只有当使能信号有效时，数据才能被写入并保存。这样一来，当初 Set 和 Reset 同时为 1 的那种冲突状态便不复存在，行为变得明确、统一，不再因电路实现不同而产生差异。

为简化描述，我们将两个输入端和一个输出端分别记为：

WE（写使能，Write Enable）

Din（数据输入，Data In）

Dout（数据输出，Data Out）

现在，将 8个门控锁存器 并排排列，构成一个整体结构：

所有锁存器的 WE 端用一条公共导线连接，实现统一控制；

每个锁存器的 Din 端则分别用独立的导线接入，用于接收各自的数据。

这样，就形成了一个能够同时存储 8个二进制信号 的门控锁存器阵列，我们称它为 8位寄存器。

在信息量上：

单个锁存器可记录 0或1，对应 1比特（bit） 信息；

8个锁存器按顺序排列，共有 2⁸ = 256 种不同的组合状态；

这 256种状态 恰好对应 1字节（Byte） 的信息容量。

对于上文所述的8位寄存器横向展开阵列结构（参见上图），每个寄存器单元需要配备一条公共的写使能信号线WE，以及8条输入数据线和8条输出数据线，因此单个单元的外部连线总数即为17条。

若采用这种横向展开的排列方式构成线性阵列，并用以记录16比特的信息，则所需输入线数量为8乘以16条，输出线数量亦为8乘以16条，再加上一条WE线，整个阵列的连线总数将随之显著增加。然而，16比特的存储规模毕竟有限，若目标容量进一步扩大至1G信息量，问题便会急剧恶化。

在此有必要对容量单位的定义作出明确说明。在本存储器体系之中，1字节被严格定义为8位，并以此作为最基本的存储单位。当涉及更大单位如1KB时，必须强调其含义并非来源于排列组合意义上的压缩或等效替代。具体而言，1字节所对应的256种可能状态，固然是由8个比特的排列组合产生，这并不存在疑义；然而，从1字节过渡到1KB的过程，并不能通过将8位寄存器排列10次并借助2的10次方等于1024这一数学关系来简化实现。事实是，1KB必须由1024个独立的8位寄存器实体构成，每一个寄存器均对应实际的物理存储空间。1GB的定义亦遵循完全相同的原则，即需要1024乘以1024再乘以1024个8位寄存器，方能容纳相应的信息量。

依据上述容量定义，若要实现1GB的存储目标，并坚持采用纯粹的线性横向展开阵列结构，则所需寄存器数量为1024的三次方个。相应地，输入线与输出线的数量各自达到8乘以1024的三次方条，两者合计后再加一条WE线，方可构成完整的互连系统。这一数量级的导线规模意味着，在给定面积的电路板或芯片基板之上，金属互连线将不可避免地占据绝大部分可用空间，而真正承担存储与逻辑功能的有源器件区域则被严重压缩，仅能分布于剩余的小部分面积之内。

此种状况所引发的后果体现在多个层面。一方面，由于导线占据过多面积，实现同等存储容量所需的芯片总面积必然显著增大，这不仅推高了制造成本，也使得存储系统在物理尺寸上难以满足电子设备对小型化的需求。另一方面，高密度的导线排布将导致信号串扰与寄生效应加剧，同时，大量电流流经密集且细长的互连线时，会产生可观的焦耳热，致使芯片功耗上升、热密度增大，进而对散热设计与系统稳定性构成严峻挑战。

综上所述，传统的线性横向展开阵列在面对GB级别的大容量存储需求时，已暴露出结构上的根本性局限。那么，针对上述由布线面积膨胀与热耗散加剧所带来的困境，应当采取何种改进策略，方才能够有效缓解乃至彻底解决这一问题呢？

上述问题的根本成因在于，每个寄存器单元内部的锁存器，其写入操作与读出操作各自依赖于一条独立的专用导线，即写入需经由特定的输入线导入数据，读出亦需经由特定的输出线导出数据，二者不可复用。以16个锁存器按线性方式排列构成的阵列为例，若将此类锁存器从原有的一维线性布局中取出，重新组织为4×4的方阵结构，则可通过两个二进制译码器来实现对其中任意一个锁存器位置的唯一寻址。具体而言，每个二进制译码器配备两条地址输入线，可产生4条输出选择线（因2的2次方等于4），两个译码器合计仅需4条地址线，即可唯一确定矩阵中的行位置与列位置，进而通过行地址线与列地址线的交叉点，精确锚定某一个锁存器。这也是内存地址术语的由来。

在实现以地址译码方式识别矩阵中每个锁存器位置的基础上，接下来的任务在于设计一种以尽可能少的导线完成数据读取与写入操作的方案。下面将对此最少接线方案展开论述。

首先考虑数据输入线Din与数据输出线Dout这两条原本各自独立的信号线。在传统锁存器结构中，数据写入与数据读出分别经由这两条不同的导线完成，因此每个锁存器需要同时占用两条数据线。倘若能够将这两条线的功能合并为一条双向数据线，使其同时承担输入与输出的职能，则该数据线便可在配合地址译码选通机制的前提下，接入公共总线，从而无需为每个锁存器保留两条独立的数据接入导线。

为此，我们可在原有锁存器结构的基础上，增设相应的控制逻辑电路（如上图），用以实现数据流向的切换控制。通过这一改进，16个锁存器的输入线和输出线总数量可由原先的32条缩减为16条，即每个锁存器仅需一条双向数据线即可同时支持写入与读出操作。进一步地，若将这16条双向数据线统一接至一条公共数据总线，则外部与阵列之间的数据交互便可最终简化为仅需一条数据线，从而在最大限度上压缩了数据互连所需的导线数量。

不过，让所有锁存器都记住一样的值显然不是我们想要的行为。我们要的是让每个锁存器记住各自不同的值。配合前面提到的地址锚定机制，我们可以通过与门电路进行一些修改，确保写使能信号、读使能信号以及输入值，只传递到地址输入所指定的那个目标锁存器。

为了存储字节而不是比特，我们可以使用八个矩阵，所有这些矩阵将共享相同的地址输入，从而让我们能使用同一个地址在各个矩阵中选择对应的锁存器。

这也就是说，把原来的线性寄存器阵列从锁存器视角改成矩阵阵列后，8位寄存器中的每个锁存器，被分别放置到了在硬件上刻蚀于8个不同位置上的存储矩阵之中。不过，我们在编写程序时（软件层面）通常并不关心这一硬件实现细节，相反，我们将字节视为连续储存的比特序列。

因此，我们可以进一步抽象，将内存概念化为一个字节列表。在这个抽象中，地址不再是不可见矩阵中的交叉点，而是这个字节列表中的索引。

这里所说的数据总线，就是指我们所有输入输出数据线的总体，也就是8位宽的那一组导线。而地址总线，则是指这个字节列表所存储的字节个数，对应到两个二进制译码器所需的地址线的总体。

最后请记住，我们今天所学习的内存类型是静态随机存取存储器（SRAM）。在后续章节中，我们还会接触到另一种类型——动态随机存取存储器（DRAM）。此外，还有一种新型晶体管——MOS管（金属氧化物半导体场效应管），它作为基础单元被用于构建逻辑门电路。

为什么需要MOS管呢？原因有二：

其一，对于SRAM，若使用传统双极型三极管，其静态功耗较高，当集成度提高时，芯片发热量将急剧增加，散热问题无法解决，从而限制了集成规模的进一步扩大。而MOS管属于电压控制器件，静态功耗极低，在相同功耗预算下可以实现更高的集成度，因此在追求大规模集成化的进程中，MOS管成为SRAM的必然选择。我们教学讲解中，为简化原理，不考虑集成化问题，因此仍使用三极管搭建SRAM。

其二，对于DRAM，其存储单元依赖于电容上的电荷来保存数据，这就要求连接电容的晶体管必须具有极高的输入阻抗，以防止电荷快速泄漏。传统双极型三极管属于电流控制器件，输入阻抗较低，无法满足这一要求，因此DRAM完全不能使用三极管。而MOS管的栅极输入阻抗极高，几乎不从电容抽取电流，恰好满足了DRAM的基本工作条件。
