神的聊天室：一个 C++/Qt 多人网络聊天室项目

神的聊天室

一个基于 C++ / Qt 的多人网络聊天室，完整实现客户端 + 服务端，代码已开源。

项目简介

这是一个基于 C++ / Qt 的多人网络聊天室系统，采用 客户端 / 服务器（C/S） 架构。

  • 服务端：基于 epoll + 线程池 的高并发模型，配合 eventfd 与线程安全发送队列，跑在 Linux 上；
  • 客户端：使用 Qt Widgets 构建，无边框深色主题界面，跑在 Windows 上。

支持用户注册、登录、公共聊天、私聊、在线用户列表、上下线实时通知等功能，是一个比较完整的网络编程练手项目。

技术栈

客户端

分类 技术
语言 C++11
GUI 框架 Qt 6（QtWidgets）
网络 QTcpSocket（异步信号槽）
数据序列化 QJsonDocument / QJsonObject / QJsonArray
构建 CMake
界面风格 QSS

服务端

分类 技术
语言 C++11
网络模型 epoll（LT 模式）+ 非阻塞 IO
并发 自定义线程池
线程通信 eventfd + SendQueue（线程安全发送队列）
数据库 MySQL 8.0
数据库连接池 自实现 MysqlPool（互斥锁 + 条件变量）
JSON 库 jsonhpp
配置 自定义 ConfigManager 读取 .conf 文件
构建 CMake

核心功能

用户模块

  • 用户注册：用户名 6 位数字、昵称、密码，用户名唯一校验；
  • 用户登录：数据库校验密码、重复登录检测；
  • 退出登录：服务端解绑 session，广播 USER_LEAVE。

聊天模块

  • 公共聊天：消息广播给所有在线用户；
  • 私聊：点击在线用户列表进入私聊模式，消息点对点发送。

在线状态

  • 登录成功广播 USER_JOIN，其他客户端实时更新列表；
  • 退出 / 断线自动广播 USER_LEAVE；
  • 在线用户列表实时刷新，带数量统计。

界面

  • 登录 / 注册 / 聊天三窗口切换（WindowManager 管理）；
  • 无边框窗口 + 自定义标题栏（最小化 / 关闭）；
  • 深色圆角 QSS 主题；
  • 网络异常、登录 / 注册失败等消息提示。

服务端亮点

  • epoll 高并发 IO 多路复用；
  • 线程池处理业务逻辑；
  • eventfd 唤醒 + 发送队列，实现线程安全异步发送；
  • MySQL 连接池，避免频繁建连；
  • SQL 转义防注入；
  • 支持 TCP 粘包 / 半包处理。

环境要求

  • Linux（服务端依赖 epoll / eventfd）
  • Qt 6.5.3
  • MySQL 8.0
  • CMake 3.10+
  • g++ 支持 C++11

使用方式

客户端：./client/src 是源码，装好 Qt 后用 CMakeLists.txt 构建即可；./client/exec 是编译好的可执行文件与依赖库，运行前把 ./client/exec/config/server.conf 里的服务端 IP 和端口改成自己的。

总结

这个项目主要目的是熟悉 C++ 和 Linux 网络编程，目前还有不少可以完善的地方：数据库直接存明文密码、网络走明文 JSON（未做哈希与 TLS 加密）、客户端缺少群组 / 好友等常见 IM 功能。如果你对高并发、epoll、Qt 开发感兴趣，可以把它作为一个不错的练手参考。
