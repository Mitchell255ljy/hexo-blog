神的聊天室

缘起：神的权柄

很久以前，世界上只有一种声音——神的。

「交流」曾经是神独占的权柄：谁能开口、谁该被听见、一句话该如何抵达另一个人，全凭神一言裁决。众生只能沉默，或是在神默许的间隙里，小心翼翼地发出一声。

可众生越来越多，万千言语汇成洪流，单凭神的一副口舌，早已应接不暇。

于是，神做了一个决定：把「说话的权力」与「消息传递的权力」，下放给众生。

神造了一座实验场——一间聊天室。凡人（客户端）向神（服务端）注册、登录、开口说话，话语便借由神之手，在众生之间流转、广播、点对点地抵达。神则退居幕后，化身一台沉默而高效的高并发服务器，只在有人到来或离去时，轻轻广播一声。

这便是「神的聊天室」。

它是什么

一个基于 C++ / Qt 的多人网络聊天室，客户端 / 服务器（C/S） 架构：

  • 服务端：epoll + 线程池 高并发模型，跑在 Linux 上；
  • 客户端：Qt Widgets 无边框深色界面，跑在 Windows 上。

内部采用「二进制帧头 + JSON 消息体」，17 种消息类型覆盖登录、注册、公共聊天、私聊、上下线、在线列表、退出登录。架构与协议细节在仓库的 README 里写得很全，这里不重复，下面重点讲怎么把它构建、跑起来。

如何构建

服务端（Linux）

依赖：gcc / g++ / cmake、MySQL 8.0，以及 epoll / eventfd（Linux 内核自带）。

第 1 步：装编译工具链

第 2 步：装 MySQL 8.0.25

按你发行版的方式装好 MySQL 8.0 服务端，并保证能 mysql 登录。

第 3 步：装 MySQL 连接库

第 4 步：建库建表

登录 MySQL，创建数据库 user，再用项目里的 ./sql/user_information.sql 在 user 库中建表。

第 5 步：改配置

打开 ./server/config/，把 server.conf、mysql.conf 里的服务端 IP、端口、数据库账号密码改成你自己的。

第 6 步：编译并运行

客户端（Windows / Qt）

依赖 Qt 6.5.3（含 QtWidgets），CMake 3.10+。

有两条路：

方式 A：直接用编译器（Qt Creator）构建

./client/src 是客户端源码。装好 Qt 后，直接用 Qt Creator 打开 ./client/CMakeLists.txt，点构建即可，无需敲任何命令。构建前先把 server.conf 里的服务端 IP 和端口改成你自己的。

方式 B：直接用编译好的可执行文件

./client/exec 里是已编译好的可执行文件与依赖库，运行前先改 ./client/exec/config/server.conf 里的 IP 和端口，然后双击运行即可。

前往 GitHub

完整的服务端 + 客户端源码、建表 SQL、编译好的客户端，都已开源：

👉 github.com/Mitchell255ljy/Shen_chatroom

欢迎 star、fork，一起交流 C++ 与 Linux 网络编程。

结语

这个项目是神用来熟悉 C++ 和 Linux 网络编程的一次实验，尚有不少可完善之处：数据库存的是明文密码、网络走的是明文 JSON（未做哈希与 TLS 加密）、客户端也还没有群组、好友等常见 IM 功能。但对想上手 epoll、线程池、Qt 网络开发的人来说，它是一份足够完整、可以直接跑起来的参考。
